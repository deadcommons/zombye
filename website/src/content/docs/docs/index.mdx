Zombye is slow-burn zombie survival in real 3D. You wake up in a house in a small early-1990s American town ringed by
forest, the day after. Everything you need is somewhere in those houses, and so are the dead.

It is also an open platform: the code is MIT or Apache-2.0, every gameplay number lives in a plain data file, and the
server speaks the [Model Context Protocol](https://modelcontextprotocol.io), so AI agents can play it, test it and
build mods for it.

<Aside type="caution" title="Pre-alpha">
Zombye is early. There are no downloads yet: you build it from source, which takes one command. Things change every
week, and these docs change with them (they live in the same repository as the code).
</Aside>

## The pieces

| Program | What it is |
|---|---|
| `zombye` | The game: a window, your survivor, the town. Single-player runs a server inside it. |
| `zombye-server` | The headless server. `--mcp` lets an agent connect over stdio; `--bench` measures performance. |

Both read the game's data from `assets/data` (or another folder with `--data`), and both read and write the same save
files.
